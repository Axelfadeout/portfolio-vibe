PORTFOLIO VITE - ISTRUZIONI RAPIDE

1. Copia tutto il contenuto di questa cartella nella root locale del repository portfolio-vibe.
2. Puoi eliminare le vecchie cartelle src e public prima della copia.
3. Apri un terminale nella cartella e lancia: npm install
4. Verifica con: npm run dev
5. Verifica la build con: npm run build
6. In GitHub Desktop esegui Commit e Push sul branch nuovo-portfolio.

IMPORTANTE: non spostare la cartella public/assets e non rinominare i file: index.html li richiama tramite /assets/...
